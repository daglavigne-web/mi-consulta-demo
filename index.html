▣  Copia de seguridad

DATOS FICTICIOS

Como abrís el HTML desde Descargas, Chrome puede no conservar el almacenamiento entre aperturas. Descargá una copia de seguridad después de importar cambios y restaurala si los registros desaparecen.

Solo datos ficticios. Esta demo procesa CSV localmente, guarda solo los datos ficticios en este navegador y únicamente acepta IDs DEMO-###. No cargues padrones ni información personal real: el archivo HTML no tiene autenticación real ni almacenamiento seguro.

Formato del CSV

Usá una primera fila con estas columnas: id,name,address. Ejemplo ficticio: DEMO-001,Martina López,Calle Azul 123 · Ciudad Ejemplo. Si el ID ya existe, actualiza ese registro; si es nuevo, agrega otro registro de prueba.

🗄️ Almacenamiento

Los registros ficticios se guardan en este navegador para que sigan disponibles al cerrar y volver a abrir el archivo en el mismo dispositivo y navegador. No se sincronizan con otros dispositivos.

🛡️ Para una versión real

Usar un servidor administrado, cuentas individuales, permisos mínimos, cifrado y registro de actividad.

📱 Acceso desde varios dispositivos

Requeriría un servicio seguro alojado y autenticación real; compartir este HTML no sincroniza información.
